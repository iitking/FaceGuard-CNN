💡 Why Global Average Pooling & Batch Normalization?

By replacing flattening with GlobalAveragePooling2D, the model eliminates massive fully-connected parameter bloat, preventing overfitting while keeping the weights compact (~5.2 MB). BatchNormalization after every convolutional block stabilizes internal covariate shift, allowing convergence in 30 epochs with superior generalization.

REST API Developer Documentation

Interactive Swagger UI →

FaceGuard-CNN provides high-speed HTTP REST endpoints for easy integration with web applications, mobile apps, CCTV RTSP processors, and IoT edge devices.

POST /api/predict Upload multipart image
Python (requests)
import requests

url = "http://localhost:8000/api/predict"
files = {"file": open("photo.jpg", "rb")}
params = {"detect_faces": True}

response = requests.post(url, files=files, params=params)
data = response.json()

print("Status:", data["primary_label"])
print("Mask Compliant:", data["is_wearing_mask"])
print("Confidence:", f"{data['confidence'] * 100:.1f}%")
cURL (Command Line)
curl -X POST "http://localhost:8000/api/predict?detect_faces=true" \
  -H "accept: application/json" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@/path/to/face.jpg"
JavaScript (Fetch API)
const formData = new FormData();
